Word Roots & Word Families

Stop memorizing words in isolation. Vocabulary is a network: one core root plus a handful of prefixes and suffixes generates an entire family of related words.

Foundational · used across Daily, Workplace & Academic English alike

I. How a Word Is Assembled

Most English words compile from up to three parts, each with a distinct job.

1. Prefix
Sets direction or state

Controls where the action points or what condition it's in.

  • con- / com- — together, jointly
  • de- — down, away, undo
  • in- / im- — into, inward
  • ex- — out, outward
2. Root
Carries the core meaning

The base concept every word in the family shares.

  • struct — to build
  • port — to carry
  • vis / vid — to see
  • spect — to look at
3. Suffix
Casts the grammatical type

Doesn't touch the core meaning — just changes what part of speech the word becomes.

  • -tion / -sion → noun
  • -ive / -ic → adjective
  • -ize / -fy → verb
  • -ly → adverb

Practice

Using the root port ("to carry") and the prefix table above, what would transport, import, and export literally mean, piece by piece?

Show answer

transport — trans- (across) + port (carry) = to carry across. import — im- (into) + port = to carry in. export — ex- (out) + port = to carry out. Same root, three directions, three related meanings — the same pattern as struct.
