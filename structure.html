🏗️ 句子结构与语法物理学

用搭建乐高（Lego）的心智模型理解英语：主干为骨，修饰为肉，向后无限延展。

🧱 一、 英语的 5 大乐高核心骨架

无论长难句多么复杂，撕掉修饰成分后，都必定归属于以下 5 种基础物理骨架：

1. 自激运动型 (主 + 谓)
Subject (主语) Intransitive Verb (不及物动词)
例句：The sun rises.（太阳升起。动作不需要传递给第三方）
2. 能量传递型 (主 + 谓 + 宾)
Subject (主语) Transitive Verb (及物动词) Object (宾语)
例句：AI changes the world.（AI 改变世界。能量从主语传递给宾语）
3. 状态镜像型 (主 + 系 + 表)
Subject (主语) Link Verb (系动词/等号) Complement (表语/状态)
例句：Code is poetry.（代码即诗篇。系动词相当于数学中的“=”）
4. 双重传递与状态赋予 (双宾 / 宾补)
Subject Verb Indirect Object Direct Object
Subject Verb Object Object Complement

🌌 二、 句子的“向后延展”向心力法则

💡 中文 vs 英文的核心差异：中文习惯把所有定语修饰语塞在名词前面（前置修饰）；而英文秉持“核心信息在前，补充细节在后”的物理原则。

中文思维（前置堆叠）：
一个 [昨天在图书馆里读完那本厚书的] 女孩 在喝咖啡。
英文物理思维（先抛核心，后置延展）：
The girl is drinking coffee [who read the thick book in the library yesterday]
后置定语从句、介词短语、分词短语，均以“挂钩方式”依次挂挂在被修饰名词的后方。

⏱️ 三、 动词时态 3×4 二维时空矩阵

时态 = 时间（Past / Present / Future） × 状态（Simple / Continuous / Perfect / Perfect Continuous）：

一般现在时 (Present)
V / V-s
规律/常态事实
现在进行时 (Continuous)
am/is/are + V-ing
此时此刻正在发生
现在完成时 (Perfect)
have/has + V-ed
过去的动作对现在的影响
