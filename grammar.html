🏛️ 句法建筑学与 5 大受力架构

💡 放弃死记语法规条：把句子视为一座建筑物，词性是建材，句式是受力骨架。

🧱 一、词性原子的工程物理角色

英语的 8 大词性不是凭空存在的，它们在句子中充当了明确的物理支撑角色：

名词 (Noun)
🏗️ 物理角色：实体建材

句子的主体或承重构件（主语/宾语）。如：apple, idea, System.

动词 (Verb)
⚡ 物理角色：动力引擎

驱动整个句子传递能量的核心。没有动词，句子就没有动力。如：run, create, is.

形容词 (Adj)
🎨 物理角色：实体涂层

依附于名词，改变实体的外表属性。如：blue, quantum, fast.

介词 (Prep)
🔗 物理角色：榫卯连接件

连接空间、时间与逻辑维度。如：in, on, under, through.

⚙️ 二、英语 5 大核心受力骨架

无论多复杂的长难句，剥离饰面后，底层必定是以下 5 种结构之一：

1. 主语 + 不及物动词 (S + V) — 自给自足型引擎

Subject + Verb

能量在主语内部消耗完毕，无需向外释放或作用于其他物体。
例：The sun shines.（太阳发光）

2. 主语 + 及物动词 + 宾语 (S + V + O) — 能量单向传递

Subject + Verb + Object

动词将能量从主语直接作用并传递给受体（宾语）。
例：Developers build platforms.（开发者构建平台）

3. 主语 + 系动词 + 表语 (S + V + C) — 状态等号 ($A = B$)

Subject + Linking Verb + Complement

系动词不传递动作能量，仅仅扮演“等号”或者状态连接梁。
例：Knowledge is power.（知识 = 力量）

4. 主语 + 动词 + 间宾 + 直宾 (S + V + IO + DO) — 双重传递

Subject + Verb + Indirect Object + Direct Object

动作同时带有一个“接收者”和一个“转移物”。
例：AI gives us clarity.（AI 给 我们 清晰感）

5. 主语 + 动词 + 宾语 + 宾补 (S + V + O + OC) — 状态追加平衡

Subject + Verb + Object + Complement

仅有宾语不足以使结构平衡，需要追加补语来描述宾语的状态或结果。
例：Code makes systems efficient.（代码使系统变得高效）
