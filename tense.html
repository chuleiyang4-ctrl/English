🌌 时态与语态的二维坐标系

时态不是 16 个死板公式，而是 时间轴 (X) × 视角状态 (Y) 的空间定位。

📐 一、时态二维物理矩阵

把时间看作横轴 $X$，把观察者的视域状态看作纵轴 $Y$，坐标轴定位如下：

观察视角 \ 时间 过去 (Past) 现在 (Present) 将来 (Future)
1. 一般态
(点状态/固有规律)
一般过去时
V-ed
I built an app.
(过去发生的既成事实)
一般现在时
V / V-s
I build apps.
(客观习惯/系统规律)
一般将来时
will + V
I will build an app.
(未发生的事实预测)
2. 进行态
(流体截帧/正在进行)
过去进行时
was/were + V-ing
I was coding when you called.
(过去某时刻的动态画面)
现在进行时
am/is/are + V-ing
I am coding now.
(此时此刻正在发生的流体)
将来进行时
will be + V-ing
I will be coding tomorrow.
(预测未来某时刻正在做)
3. 完成态
(跨时间连接/累积效应)
过去完成时
had + V-pp
I had launched it before 2025.
(“过去的过去”已完成)
现在完成时
have/has + V-pp
I have built three sites.
(过去的动作对现在造成了结果)
将来完成时
will have + V-pp
I will have finished by June.
(到未来某个点时将已完成)

🔄 二、语态 (Voice)：焦点与能量方向

主动语态与被动语态的本质，是观察者视角与能量传递方向的切换：

1. 主动语态 (Active)：焦点在“能量源头”（施动者）
The server processed the request.
（服务器释放能量 ➔ 作用于请求）
2. 被动语态 (Passive)：焦点在“受体对象”（受动者），公式：be + V-pp
The request was processed by the server.
（请求接收能量 ➔ 施动者被移至背景或省略）
