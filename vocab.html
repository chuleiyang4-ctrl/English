🌐 词汇网络与词根算法

💡 告别孤立记忆：词汇是网络拓扑图。1 个核心 API（词根）+ 动态参数（词缀）= 裂变整个词汇库。

⚙️ 一、词汇的三段式编译算法

单词的生成过程与软件编译类似，由三个核心模块组装而成：

1. 前缀 (Prefix)

物理角色：方向/状态参数

控制动作发生的空间位置与逻辑状态。

  • con / com- : 聚拢、共同
  • de- : 向下、剥离、破坏
  • in / im- : 向内、进入
  • ex- : 向外、排出
2. 词根 (Root)

物理角色：核心 API / 基类

承载最根本的物理动作概念。

  • struct : 建造、搭建
  • port : 搬运、港口
  • vis / vid : 观察、视界
  • spect : 看、注视
3. 后缀 (Suffix)

物理角色：类型强转 (Type Cast)

不改变词义核心，只修改数据接口类型。

  • -tion / -sion : 转为 [名词]
  • -ive / -ic : 转为 [形容词]
  • -ize / -fy : 转为 [动词]
  • -ly : 转为 [副词]

🌳 二、节点拓扑网络实战：以 struct (建造) 为例

观察同一个基础 API 如何通过传入不同参数，裂变成一个完整的词汇网络树：

BASE_ROOT: struct (物理含义：建造 / 搭建)
con- (共同) + struct (建造) ➔ construct [动词] 建设、构建
└── construct + -ion ➔ construction [名词] 建筑物、工程
└── construct + -ive ➔ constructive [形容词] 建设性的
de- (向下/破坏) + struct (建造) + -ion ➔ destruction [名词] 毁灭、破坏
└── de- + struct + -ive ➔ destructive [形容词] 毁灭性的
infra- (下层/基础) + struct (建造) + -ure ➔ infrastructure [名词] 基础设施、底层架构
in- (向内) + struct (建造) ➔ instruct [动词] 指导、灌输知识（在内部构建知识框架）
└── instruct + -or ➔ instructor [名词] 导师、教练
